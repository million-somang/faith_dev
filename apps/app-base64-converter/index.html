Base64 인코딩·디코딩 & 데이터 변환 센터

텍스트 및 이진 파일의 Base64 인코딩과 디코딩을 원클릭으로 처리하세요. UTF-8 한글 완벽 지원 및 Data URL 생성 가이드를 제공하는 VERA 유틸리티입니다.

🔤 6비트 아스키 변환 원리(RFC 4648 표준)

Base64는 8비트 2진 데이터를 64개의 출력 가능한 아스키(ASCII) 문자(A-Z, a-z, 0-9, +, /)로 변환하는 인코딩 방식입니다. 3바이트(24비트)의 데이터를 4개의 6비트 단위로 나누어 변환하며, 빈자리는 패딩 문자(=)로 채워 데이터의 무결성을 보장합니다.

🇰🇷 UTF-8 한글 및 다국어 텍스트 완벽 인코딩

표준 자바스크립트의 btoa/atob 함수에서 발생하는 한글 인코딩 오류(Latin1 한계)를 자체 UTF-8 바이트 변환 알고리즘으로 해결하여 한글, 한자, 이모지 등 모든 다국어 텍스트를 깨짐 없이 깨끗하게 인코딩하고 복원합니다.

🖼️ Data URL 이미지 인라인 임베딩 활용

작은 아이콘이나 로고 이미지를 Base64 Data URL(`data:image/png;base64,...`)로 인코딩하여 HTML이나 CSS에 직접 삽입하면, 별도의 HTTP 요청 없이 즉시 이미지를 렌더링할 수 있어 초기 페이지 로딩 속도를 향상시킬 수 있습니다.

🌐 웹 개발 및 네트워크 프로토콜 실무

이메일 전송(MIME 규격), 웹소켓 바이너리 데이터 전달, JWT(JSON Web Token) 페이로드 분석 등 다양한 웹 개발 실무 현장에서 즉시 활용할 수 있는 직관적인 듀얼 입력/출력 창을 제공합니다.

💬 자주 묻는 질문 (FAQ)

Q. Base64로 인코딩하면 왜 파일 용량이 늘어나나요?

A. 3바이트의 이진 데이터를 4바이트의 아스키 문자로 변환하므로 약 33%의 용량 증가가 발생합니다. 이는 모든 시스템에서 데이터 손실 없이 안전하게 텍스트로 전달하기 위한 기술적 트레이드오프입니다.

Q. Base64는 암호화 기술인가요?

A. 아닙니다. Base64는 누구나 동일한 규칙으로 복원(디코딩)할 수 있는 인코딩 규약이며, 보안을 위한 기밀성을 제공하지 않으므로 민감한 비밀번호 등은 반드시 AES나 RSA 같은 전문 암호화 알고리즘을 사용해야 합니다.
