# 성좌의 잔향: 부서진 하늘의 조율자들 (Echoes of the Firmament)
## 🎮 Phaser 3 기반 2D 파이널 판타지 배틀 시스템 구현 매뉴얼 (game-manual.md)

> **문서 버전**: 1.0  
> **엔진 및 기술 스택**: Phaser 3 (HTML5 Canvas/WebGL 2D) + React 18 + TypeScript + Tailwind CSS v4  
> **뷰포트 규격**: `miniapp.md` 표준 450px × 850px 독립 팝업 (반응형 풀 하이트 레이아웃)  
> **디자인 원칙**: 100% 라이트 뉴모피즘 테마 + 레트로 2D 픽셀 아트 + 최고급 모션/파티클 연출

## 📌 1. 개요 및 구현 비전

본 매뉴얼은 《성좌의 잔향: 부서진 하늘의 조율자들》을 **Phaser 3 2D 게임 엔진**으로 렌더링하고, 클래식 파이널 판타지 시리즈(FF IV~VI 스타일)의 상징인 **사이드뷰(Side-View) ATB/턴제 배틀 시스템**을 현대적인 감각으로 구현하기 위한 표준 기술 지침입니다.

### 핵심 구현 목표
1. **Phaser 3 + React 하이브리드 아키텍처**:
   - 캔버스 영역(450px × 520px): Phaser 3가 캐릭터 애니메이션, 타일맵, 카메라 셰이크, 마법 파티클, 사이드뷰 전투를 60FPS로 전담 렌더링.
   - UI/HUD 오버레이 영역(450px × 330px): React 18이 상단 고도계 HUD, 스토리 텍스트 박스, ATB 커맨드 메뉴, 파티 채팅을 라이트 뉴모피즘으로 선언적 관리.
2. **정통 사이드뷰 파이널 판타지 전투 (FF Battle System)**:
   - **우측**: 4인 조율자 파티 (전사, 백마도사, 흑마도사, 몽크)가 세로 열로 포진.
   - **좌측**: 몬스터 및 보스가 위치하며 크기와 위압감에 따라 스케일 차등 적용.
   - 행동 선택 시 캐릭터가 **앞으로 한 걸음 대시(Step-forward)**하여 무기를 휘두르고 파티클을 터뜨린 뒤 원위치 복귀.
3. **ATB(Active Time Battle) 및 게이지 시스템**:
   - 각 영웅의 민첩성(AGI)에 따라 게이지가 실시간으로 차오름.
   - 팝업 및 모바일 조작 편의를 위해 메뉴 오픈 시 시간이 일시 정지되는 **Wait 모드** 탑재.

## 🏗️ 2. 시스템 아키텍처 및 씬(Scene) 설계

Phaser 3의 씬 관리자를 활용하여 모듈화된 4단계 씬 라이프사이클을 구축합니다.

```
[BootScene] ──> [PreloadScene] ──> [FieldScene] ──(인카운터/보스전)──> [BattleScene]
                                        │                                   │
                                        └── [AirshipScene] (비공정 비행) ───┘
```

### 2.1 BootScene & PreloadScene
- **BootScene**: 게임 캔버스 해상도 초기화, 스케일 매니저(`Phaser.Scale.FIT`), 오디오 컨텍스트 기동.
- **PreloadScene**:
  - 캐릭터 4종(전사, 백마도사, 흑마도사, 몽크)의 16×24 / 24×32 스프라이트시트 로드 (대기, 공격, 마법 영창, 피격, 승리 포즈).
  - 몬스터 및 보스 스프라이트 (고블린, 울프, 크리스탈 스켈레톤, 네더 크라켄, 대사제 에제키엘).
  - 이펙트 애니메이션: 슬래시(Slash), 화염구(Fire), 번개(Thunder), 케알라 성광(Heal Chime).

### 2.2 FieldScene (월드 및 던전 탐험)
- **뷰**: 2D 탑다운(Top-down) RPG 타일맵.
- **조작**: 가상 D-패드 또는 터치/클릭 목적지 이동 및 키보드(WASD/방향키).
- **상호작용**: 보물상자 개봉, 장로회 NPC 대화, 결정 파편 조사.
- **인카운터**: 풀숲/던전 타일 이동 시 걸음 수에 따른 무작위 전투 돌입 (화면 모자이크/플래시 트랜지션 연출).

### 2.3 AirshipScene (비공정 천공 비행 모드)
- 제1막에서 비공정을 복원한 후 오픈되는 특수 씬.
- 아래로 구름 바다가 스크롤되는 모드 7 스타일의 2D 패럴랙스(Parallax) 배경 스크롤.
- 천공 대륙 '에테리아'와 하계 '님버스' 사이의 구름 장벽을 돌파하는 컷씬 및 자유 이동.

### 2.4 BattleScene (파이널 판타지 사이드뷰 전투) - **핵심 씬**
- **해상도**: 너비 450px, 높이 400px (상단 캔버스).
- **배경**: 현재 던전 테마에 맞춘 배틀필드 (바람의 언덕, 크리스탈 묘지, 종언의 첨탑).
- **등장인물 배치**:
  - 파티원 4명: (X: 360px, Y: 100px, 170px, 240px, 310px) 대각선 정렬.
  - 적군 1~3체: (X: 80px ~ 140px, Y: 120px ~ 280px) 균형 배치.

## ⚔️ 3. 파이널 판타지 전투 메커니즘 상세 사양

### 3.1 턴 및 ATB(Active Time Battle) 시스템
1. **게이지 누적**:
   $$\text{ATB 속도} = \frac{\text{AGI} \times 1.5 + 20}{100} \quad (\text{초당 퍼센트})$$
2. **턴 도달**:
   - 게이지가 100%에 도달한 캐릭터의 발밑에 황금빛 마법진 인디케이터가 켜짐.
   - 캐릭터가 반 걸음 앞으로 나오며 React 커맨드 박스가 해당 캐릭터의 행동 메뉴로 자동 전환.
3. **Wait 모드**:
   - 마법이나 아이템 등의 서브 메뉴를 고르는 동안에는 모든 캐릭터와 몬스터의 ATB 진행이 일시 정지되어 모바일에서도 여유롭게 전략 수립 가능.

### 3.2 5대 전투 커맨드

| 커맨드 | 발동 효과 | 애니메이션 & 연출 |
|---|---|---|
| **[1] 공격 (Attack)** | 대상 적에게 기본 물리 공격력 기준 타격 | 영웅이 적 앞으로 고속 대시 ➡️ 2프레임 검/권격 모션 ➡️ 화면 슬래시 FX 및 타격음 ➡️ 제자리 복귀 |
| **[2] 마법 (Magic)** | MP를 소모하여 직업별 고유 원소/신성 마법 발동 | 제자리에서 손을 올리는 영창 모션 ➡️ 발밑 원형 마법진 회전 ➡️ 적진에 파이어 폭발/블리자드 결빙/힐 차임 FX |
| **[3] 기공 (Monk Skill)** | 몽크 고유 스킬: 백열각(4연타), 기합, 파동권 | 잔상 이펙트와 함께 4회 연속 타격 파티클 ➡️ 데미지 숫자 4연속 팝업 |
| **[4] 방어 (Defend)** | 다음 턴까지 받는 데미지 50% 경감 | 캐릭터가 방패/가드 자세를 취하며 파란색 수호 방어막 셰이딩 유지 |
| **[5] 리미트 (Limit)** | '시원 결정의 공명' 게이지 100% 시 사용 가능한 궁극기 | 화면 암전 ➡️ 결정 빛 기둥 폭발 ➡️ 4인 전원 합동 일격 연출 |

### 3.3 데미지 & 상태이상 렌더링
- **데미지 팝업 (Floating Numbers)**:
  - 일반 타격: 굵은 흰색/주황색 텍스트가 위로 포물선을 그리며 바운스.
  - 치명타(Critical): 황금색 대형 폰트로 화면 가벼운 흔들림(Camera Shake 0.01).
  - 회복(Heal): 에메랄드 초록색 텍스트와 십자(+) 반짝임 파티클.
  - 회피(Miss): 회색 이탤릭 텍스트.
- **상태 애니메이션**:
  - HP 20% 이하: 헐떡이며 한쪽 무릎을 꿇는 빈사(Danger) 모션.
  - 전투 불능(KO): 흑백 톤으로 쓰러진 상태.
  - 승리(Victory): 전원 점프 및 무기를 치켜드는 FF 승리 포즈 반복.

## 🌉 4. React와 Phaser 3의 양방향 브리지 (`EventBus`)

게임의 렌더링 성능과 웹 앱의 생산성을 동시에 잡기 위해 **EventBus 패턴**을 사용합니다.

```
       [Phaser 3 Canvas]                                [React 18 UI Layer]
  (전투 애니메이션, 파티클, 씬)                     (HUD, 텍스트 박스, 커맨드 버튼)
              │                                                ▲
              │ ─── Event: HERO_TURN_READY (heroId, stats) ─── │ (커맨드 박스 활성화)
              │ ─── Event: DAMAGE_DEALT (target, amount) ───── │ (HP바 동기화)
              │ ─── Event: BATTLE_VICTORY (rewards) ────────── │ (결과 모달 노출)
              ▲                                                │
              │ ─── Action: EXECUTE_COMMAND (type, target) ─── │ (공격/마법 명령 전송)
              │ ─── Action: SELECT_TARGET (monsterIndex) ───── │ (타겟 지정)
```

### 브리지 코드 인터페이스 표준 (`src/bridge/EventBus.ts`)
```ts
import Phaser from 'phaser';

export const EventBus = new Phaser.Events.EventEmitter();

// 주요 이벤트 정의
export const GAME_EVENTS = {
  // Phaser -> React
  BATTLE_START: 'BATTLE_START',
  HERO_TURN_READY: 'HERO_TURN_READY',
  ACTION_EXECUTED: 'ACTION_EXECUTED',
  HP_MP_CHANGED: 'HP_MP_CHANGED',
  BATTLE_VICTORY: 'BATTLE_VICTORY',
  BATTLE_DEFEAT: 'BATTLE_DEFEAT',
  AIRSHIP_UNLOCKED: 'AIRSHIP_UNLOCKED',

  // React -> Phaser
  COMMAND_ATTACK: 'COMMAND_ATTACK',
  COMMAND_MAGIC: 'COMMAND_MAGIC',
  COMMAND_SKILL: 'COMMAND_SKILL',
  COMMAND_DEFEND: 'COMMAND_DEFEND',
  PAUSE_GAME: 'PAUSE_GAME',
  RESUME_GAME: 'RESUME_GAME',
};
```

## 🌐 6. 온라인 파티 멀티플레이어 동기화 방안

1. **호스트-클라이언트 권위 모델**:
   - 파티 방장(Leader)의 턴 타이머 및 보스 AI 연산 결과를 WebSocket / API 서버를 통해 참가자들에게 실시간 브로드캐스팅.
2. **동기화 대상 데이터**:
   - 각 플레이어의 착수 커맨드(예: 1번 슬롯 전사의 [실드 배시], 4번 슬롯 몽크의 [백열각]).
   - 보스의 광역 공격 타겟 및 남은 체력 게이지.
3. **가상 파티원 (AI 어시스트)**:
   - 솔로 플레이 시에는 나머지 3개 슬롯을 각 직업의 AI 아키타입(오토 힐, 속성 공격, 가드)이 자동으로 보조하여 1인 플레이에서도 정통 4인 파티의 재미를 100% 보장.

## 📋 7. 구현 로드맵 및 개발 순서

1. **Step 1: Phaser 3 의존성 설치 및 기본 캔버스 컨테이너 셋업**
   - `npm install phaser --workspace=ffrpg`
   - React 컴포넌트 내 Phaser 게임 인스턴스 마운트 및 언마운트 라이프사이클 관리
2. **Step 2: 에셋 및 절차적 픽셀 스프라이트 생성기 구축**
   - 4대 직업(전사, 백마, 흑마, 몽크)과 적 몬스터의 2D 스프라이트 렌더링
3. **Step 3: BattleScene 및 사이드뷰 애니메이션 엔진 구축**
   - 대기 ➡️ 대시 타격 ➡️ 슬래시 파티클 ➡️ 데미지 팝업 ➡️ 복귀 트윈(Tween) 애니메이션
4. **Step 4: ATB 게이지 및 커맨드 시스템 연동**
   - EventBus를 통한 React 커맨드 입력과 Phaser 액션 동기화
5. **Step 5: 스토리 4막 보스 및 컷씬 결합**
   - 제1막(골렘) ➡️ 제2막(네더 크라켄) ➡️ 제3막(바하무트의 허상) ➡️ 제4막(대사제 에제키엘)
   - 비공정 출항 연출 및 대단원 엔딩
6. **Step 6: 빌드, 무결성 검증 및 배포**
   - `faithlink` 0건 검증, TypeScript 컴파일 검증, 원격 서버 배포
